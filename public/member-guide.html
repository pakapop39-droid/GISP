Access

เข้าสู่ระบบและตั้งรหัสผ่านใหม่

  1. เปิด หน้าเข้าสู่ระบบ
  2. กรอกอีเมลที่ใช้สมัครบัญชีบริษัท และรหัสผ่านอย่างน้อย 10 ตัวอักษร
  3. กด เข้าสู่ระบบ ระบบจะพาไปยังพื้นที่ตามสิทธิ์ของบัญชี

ถ้าจำรหัสผ่านไม่ได้

  1. กด ลืมรหัสผ่าน ที่หน้าเข้าสู่ระบบ
  2. กรอกอีเมลบัญชีเดิมให้ตรงทุกตัว แล้วกดส่งลิงก์
  3. ตรวจ Inbox, Spam และ Junk จากนั้นเปิดลิงก์และตั้งรหัสใหม่
  4. กลับมาเข้าสู่ระบบด้วยรหัสใหม่
ข้อควรระวังอย่าส่งรหัสผ่าน ลิงก์รีเซ็ต หรือ OTP ให้ผู้อื่น และควรออกจากระบบเมื่อใช้เครื่องสาธารณะ

01 · Dashboard

ภาพรวมงานของบริษัท

หน้าแรกหลังล็อกอิน แสดงรายการที่ต้องดำเนินการ, Order ที่กำลังผลิต, Shipment ระหว่างขนส่ง, นัดส่ง 7 วันข้างหน้า, Claim ที่เปิดอยู่ และยอดที่ยังต้องชำระ

  1. ดูช่อง ต้องดำเนินการ ก่อน เพื่อไม่ให้พลาดงานเร่งด่วน
  2. กดรายการที่ต้องทำ ระบบจะเปิดหน้าต้นทางให้
  3. ดูเวลาอัปเดตด้านล่างเพื่อยืนยันว่าข้อมูลเป็นรอบล่าสุด

02 · Product catalog

ค้นหาและเลือกสินค้า

  1. เปิดเมนู Catalog สินค้า
  2. ค้นหาด้วยชื่อสินค้า, SKU, วัสดุ หรือหมวดหมู่
  3. เลือกหมวดหมู่ และเรียงตามราคา, Lead time, ชื่อ หรือสินค้าใหม่
  4. กดการ์ดสินค้าเพื่อดูรูป ขนาด สเปก วัสดุ MOQ การรับประกัน และเอกสารที่ดาวน์โหลดได้
  5. เลือก Variant/Option และจำนวน แล้วเลือกโครงการที่ต้องการ
  6. กด เพิ่มเข้าโครงการ
เรื่องราคาที่ควรรู้ราคา Member ที่แสดงเป็นราคาก่อน VAT และระบบแสดงราคาขายแนะนำให้แล้ว หากเลือก Option ที่มีราคาเพิ่ม ระบบจะปรับยอดตามตัวเลือก
ถ้ายังไม่มีโครงการให้ไปเมนู “โครงการของฉัน” สร้างโครงการก่อน แล้วกลับมาเพิ่มสินค้าอีกครั้ง

03 · Project workspace

สร้างโครงการและเตรียมสั่งซื้อ

สร้างโครงการใหม่

  1. เปิดเมนู โครงการของฉัน แล้วกรอกชื่อโครงการและประเภท
  2. กรอกชื่อลูกค้าปลายทาง ที่อยู่โครงการ และข้อมูลติดต่อ
  3. ระบุวันที่ต้องการสินค้า แล้วกด สร้างโครงการ

จัดรายการสินค้าในโครงการ

  1. เปิดโครงการ และเพิ่มพื้นที่ เช่น ห้องนั่งเล่น ห้องนอน หรือล็อบบี้
  2. เพิ่มสินค้า เลือกพื้นที่ Variant/Option และจำนวน
  3. ตรวจราคาและสเปก แล้วกด ยืนยันพร้อมสั่ง ทีละรายการ
  4. เลือกสินค้าที่พร้อมสั่ง ระบุจำนวน แล้วกด สร้าง Order และยอดชำระ 50/50
ความสามารถเพิ่มเติมในโครงการ

ดาวน์โหลด Product Schedule เป็น PDF หรือ Excel, แก้ไขรายการก่อนสั่ง และส่งคำขอเข้าชม Showroom พร้อมวันเวลาและจำนวนผู้เข้าชมได้

04 · Custom RFQ

ขอราคาสินค้าสั่งทำ

  1. สร้างโครงการก่อน แล้วเปิดเมนู Custom RFQ
  2. กดสร้างคำขอ เลือกประเภท และเลือกสินค้าเดิมเป็นต้นแบบถ้ามี
  3. กรอกชื่อรายการ รายละเอียด ขนาดเป็นมิลลิเมตร จำนวน วัสดุ สี และฟังก์ชัน
  4. เลือกโครงการ/พื้นที่ และกด บันทึกร่างและไปขั้นตอนถัดไป
  5. แนบไฟล์ PDF, JPG, PNG, DWG หรือ DXF ตามบทบาทของไฟล์
  6. ตรวจข้อมูล แล้วกด ส่งคำขอให้ GISP
ถ้า GISP ขอข้อมูลเพิ่มสถานะจะเป็น “ต้องการข้อมูลเพิ่มเติม” ให้เปิดคำขอ อ่านข้อความ แก้ข้อมูล/แนบไฟล์ แล้วกด “ส่งข้อมูลเพิ่มเติม”

05 · Custom quotation

ตรวจและตอบรับใบเสนอราคา

  1. เปิดเมนู ใบเสนอราคา หรือกดจาก Custom Request ที่พร้อมเสนอราคา
  2. ตรวจ Revision, รายการ, สเปก, ราคา, VAT, Lead time และวันหมดอายุ
  3. ดาวน์โหลด PDF เก็บไว้ได้
  4. หากถูกต้อง กด ยอมรับใบเสนอราคา แล้วกดยืนยัน
  5. หากไม่ถูกต้อง กด ปฏิเสธ ระบุเหตุผล เพื่อให้ GISP จัดทำ Revision ใหม่
ตรวจให้ครบก่อนยอมรับเมื่อยอมรับแล้ว Revision จะถูกล็อก และระบบสร้างรายการพร้อมสั่งซื้อในโครงการทันที

06 · Orders & payment

ติดตาม Order และส่งหลักฐานชำระเงิน

  1. เปิดเมนู ออเดอร์และชำระเงิน แล้วค้นหาด้วยเลข Order หรือชื่อโครงการ
  2. เปิด Order เพื่อตรวจรายการ สเปก ราคาก่อน VAT, VAT และยอดรวม
  3. ดูงวดชำระ 50/50 และยอดคงเหลือของแต่ละงวด
  4. เลือกงวด กรอกยอดและวันเวลาโอน แนบสลิป PDF/JPG/PNG
  5. กด ส่งให้ Finance ตรวจ แล้วติดตามผลใน “ประวัติสลิปและผลตรวจ”
  6. ติดตามสถานะผลิต ขนส่ง และส่งมอบจาก Timeline ของ Order
กรณีต้องการยกเลิกก่อน Finance ตรวจมัดจำ ระบบยกเลิกได้ทันที หลังตรวจมัดจำแล้ว Admin ต้องพิจารณา และระบบไม่คืนเงินอัตโนมัติ

07 · After-sales claim

แจ้งปัญหาหลังส่งมอบ

  1. เปิดเมนู Claim หลังส่งมอบ และกดเปิด Claim ใหม่
  2. เลือกสินค้าที่ส่งมอบแล้ว เลือกประเภทปัญหาและระดับความเร่งด่วน
  3. ระบุจำนวน วันที่พบ หัวข้อ รายละเอียด สภาพบรรจุภัณฑ์ และการแก้ไขชั่วคราว
  4. แนบหลักฐาน PDF/JPG/PNG/MP4 ขนาดไม่เกิน 25 MB
  5. กด ส่ง Claim ให้ทีมตรวจสอบ และติดตาม Timeline
  6. หากทีมขอข้อมูลเพิ่ม ให้ใส่รายละเอียด/แนบไฟล์และส่งกลับ
  7. เมื่อแก้ไขแล้ว ให้เลือก “ยืนยันว่าแก้ไขแล้ว”, “ยังมีปัญหา” หรือ “ขอให้ติดต่อกลับ”
เงื่อนไขสำคัญเปิด Claim ได้เฉพาะสินค้าที่มีสถานะส่งมอบสำเร็จแล้ว

08 · Reports & history

ดูรายงานและประวัติรายการ

รายงานของฉัน

เลือกประเภทรายงาน ช่วงวันที่ และสถานะ จากนั้นกดใช้ตัวกรอง สามารถกดเปิดรายการต้นทางหรือ Export CSV เพื่อนำไปใช้งานต่อได้

ประวัติรายการ

ใช้ตรวจ Project และ Order ที่เคยทำ รายการนี้แสดงเฉพาะข้อมูลที่ Member มีสิทธิ์เห็น และไม่แสดงต้นทุนหรือข้อมูลภายในของ Supplier

09 · Company profile

แก้ไขข้อมูลบริษัท

  1. เปิดเมนู ข้อมูลบริษัท แล้วกด แก้ไขข้อมูล
  2. ตรวจชื่อผู้ติดต่อ บริษัท เลขภาษี ประเภทธุรกิจ และที่อยู่
  3. กรอกพื้นที่ให้บริการและสินค้าที่สนใจ โดยคั่นแต่ละรายการด้วยจุลภาค
  4. กด บันทึกข้อมูล

การแก้ข้อมูลของบัญชีที่อนุมัติแล้วจะบันทึกทันที โดยไม่ส่งอนุมัติใหม่

Troubleshooting

ถ้าใช้งานไม่ได้ ให้ตรวจตามนี้

อาการวิธีแก้ทีละขั้น
ล็อกอินไม่ได้ตรวจอีเมลให้ตรง → ปิด Caps Lock → กดลืมรหัสผ่าน → ตั้งรหัสใหม่อย่างน้อย 10 ตัวอักษร
อีเมลรีเซ็ตไม่มารอ 2–5 นาที → ตรวจ Spam/Junk → ค้นหาคำว่า GISP/InsForge → ส่งใหม่หนึ่งครั้งด้วยอีเมลเดิม
Catalog ว่างล้างคำค้นและตัวกรอง → โหลดหน้าใหม่ → ตรวจว่าบัญชีบริษัทได้รับอนุมัติและยัง Active
เพิ่มสินค้าไม่ได้สร้างโครงการก่อน → เลือก Variant/Option ที่จำเป็น → ใส่จำนวนมากกว่า 0 → กดเพิ่มอีกครั้ง
สร้าง Order ไม่ได้เปิดโครงการ → กด “ยืนยันพร้อมสั่ง” ให้สินค้า → ติ๊กเลือกรายการและจำนวน → สร้าง Order
ส่งไฟล์ไม่ได้ตรวจชนิดไฟล์ตามที่หน้าจอรองรับ → ลดขนาดไฟล์ → เปลี่ยนชื่อไฟล์ไม่ให้มีอักขระพิเศษ → ลองใหม่
ข้อมูลไม่อัปเดตกดโหลดใหม่ในหน้านั้น → รีเฟรชเบราว์เซอร์ → ออกจากระบบแล้วเข้าใหม่
ก่อนแจ้งทีมช่วยเหลือเตรียมเลขอ้างอิง เช่น SKU, Project, Custom Request, Quotation, Order หรือ Claim พร้อมภาพหน้าจอและเวลาที่พบปัญหา
