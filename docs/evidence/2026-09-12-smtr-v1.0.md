## Safety and limitations

- The guard executes before the dynamic SDK import/client creation and requires both linked metadata and environment URLs to match the approved Development allowlist.
- Accounts use reserved `@example.com` addresses and `autoConfirm`; no outbound email is sent.
- Reports contain no password, API key, access token, refresh token or share token.
- Cleanup is dry-run by default. It completes the full five-company integrity preflight before any optional mutation. Optional execution is logical deactivation only and retains auth, transaction, audit and security history.
