## งานที่ยังไม่พิสูจน์

- `DR-024`: จุดสร้าง Shipment ปฏิเสธตามคาดแล้ว แต่ยังไม่ทดสอบ **คำสั่ง Dispatch** กับ Shipment ที่สร้างไว้ก่อน แล้วทำให้ Gate เปลี่ยนเป็นไม่ผ่าน (`QC FAILED` บน R02) จึงยังไม่ให้ DR-024 ทั้งรายการเป็น PASS
- `DR-012`: PO Version และ Supplier Acknowledgement ของ R01 ยังไม่มีหลักฐานที่ตรวจย้อนกลับได้; ไม่สร้างคำตอบรับ Supplier สมมติ
- ไม่มีการส่งหลักฐานโอน ตรวจรับเงิน บันทึก QC หรือเปลี่ยนสถานะ Shipment ใน R02 ณ เวลาบันทึกนี้ ไม่มี Shipment R02 จากคำสั่งที่ถูกปฏิเสธ
- ยังไม่ได้ตรวจ Backend Audit/Event สำหรับคำสั่งที่ถูกปฏิเสธ; ไม่อ้างว่ามีหรือไม่มี Audit โดยไม่มีหลักฐาน
- หน้าจออนุญาตให้รับเข้าคลังและยืนยัน Consolidation จาก Supplier Order ที่ยัง “ไม่มี PO” ในชุด R02; เป็นข้อสังเกตด้านลำดับงาน ไม่ถือเป็นการรับรองว่าขั้นตอนนี้ถูกต้องตาม SOP
