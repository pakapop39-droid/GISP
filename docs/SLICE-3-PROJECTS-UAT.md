## ขั้นตอนตรวจตามลำดับ

1. เข้าระบบด้วยบัญชี **Member** แล้วเปิดเมนู **โครงการของฉัน**
   - ต้องเห็นโครงการ `Slice 3 Project A ...` และเห็นเฉพาะข้อมูลของบริษัทนี้
2. เปิดโครงการ ตรวจส่วน **ข้อมูลโครงการ** และ **พื้นที่ในโครงการ**
   - แก้ชื่อ/วันที่/ที่อยู่หรือเพิ่มพื้นที่ แล้วกดบันทึก ต้องสำเร็จและข้อมูลยังอยู่หลัง Refresh
3. ที่ **รายการสินค้าในโครงการ** กด **แก้ไข**
   - เปลี่ยนพื้นที่ จำนวน Variant หรือ Option แล้วบันทึก ต้องเห็นค่าใหม่และสถานะ `READY_TO_ORDER`
4. ทดลองเพิ่มสินค้าจาก Catalog เข้าโครงการ
   - เลือกพื้นที่ สินค้า Variant/Option และจำนวน แล้วกด **เพิ่มเข้าโครงการ** ต้องมีรายการใหม่โดยไม่ต้องทำ RFQ
5. ดาวน์โหลด **PDF** และ **Excel**
   - ต้องเปิดได้ มีโครงการ/ลูกค้า/พื้นที่/SKU/สินค้า/Option/จำนวน/ราคาสมาชิก/ราคาแนะนำ/ค่าขนส่ง/Lead time/หมายเหตุ
   - ก่อนจบ Visit ต้องแสดงว่า Supplier ยังไม่เปิดเผย
6. ในส่วน **ขอเข้าชม Showroom** เลือกสินค้า กำหนดวันอนาคต จำนวนผู้เข้าชม และส่งคำขอ
   - ต้องเห็นสถานะ **รอตรวจ** และต้องไม่เห็น Supplier ID/ชื่อ/ที่อยู่/ข้อมูลติดต่อ
7. ออกจากระบบ แล้วเข้าด้วยบัญชี **Admin** เปิดเมนู **Showroom Visit**
   - ต้องเห็นคำขอของ Member พร้อมโครงการ สินค้า วันเวลา และปุ่ม **อนุมัติ/ไม่อนุมัติ**
8. กด **อนุมัติ** และใส่รายละเอียดนัดหมาย
   - กลับเข้าบัญชี Member ต้องเห็นสถานะ **อนุมัติแล้ว** พร้อมรายละเอียดนัดหมาย แต่ยังไม่เห็น Supplier
9. กลับบัญชี Admin แล้วกด **เสร็จสิ้น**
   - กลับ Member ต้องเห็นข้อมูล Supplier และ PDF/Excel ต้องมีข้อมูล Supplier ด้วย
10. กลับบัญชี Admin แล้วกด **ถอนสิทธิ์** พร้อมระบุเหตุผล
    - กลับ Member ต้องเห็นว่าสิทธิ์ถูกถอน พร้อมเหตุผล และข้อมูล Supplier ต้องหายจากหน้าจอ/PDF/Excel
11. ตรวจหน้าจอ Desktop และ Mobile แบบย่อ
    - ต้องไม่มีข้อความทับกัน หน้าไม่ขาว และไม่มี Error Overlay
12. แจ้งผลกลับ
    - ถ้าผ่านทั้งหมด ให้ตอบ `อนุมัติ UAT และ Merge ปิด Slice 3`
    - ถ้าพบปัญหา ส่งภาพหน้าจอพร้อมเลขขั้นตอนที่ไม่ผ่าน
