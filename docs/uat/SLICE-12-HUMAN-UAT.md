2. เปิดลิงก์เดียวกันบนคอมพิวเตอร์

   - ต้องเห็น Catalog ที่เตรียมไว้และเปิดหน้าแก้ไขได้
4. เปลี่ยนชื่อหรือข้อความแนะนำ แต่ยังไม่กด Publish
   - หน้า Preview ต้องเห็น Draft ใหม่ ส่วนลิงก์ลูกค้าต้องยังเห็น Snapshot เดิม
5. กด `เผยแพร่ Snapshot ใหม่`
   - ลิงก์ลูกค้าต้องเปลี่ยนมาแสดงข้อมูล Draft รอบล่าสุดพร้อมกัน
6. กด `เปลี่ยนลิงก์`
   - ลิงก์เก่าต้องเปิดไม่ได้ และลิงก์ใหม่ต้องเปิดได้
7. กด `ปิดลิงก์`
   - ลิงก์ลูกค้าต้องเปิดไม่ได้ทันที
