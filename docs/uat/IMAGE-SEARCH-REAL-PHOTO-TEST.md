เพื่อทดสอบให้ใกล้กับการใช้งานจริง ต้องใช้ภาพถ่ายใหม่ที่ไม่ได้อยู่ใน Catalog
ส่งรูปผ่านบทสนทนานี้หรือวางไว้ในโฟลเดอร์งานได้ โดยไม่ต้องตั้งค่า AI หรือส่ง API key

## รูปที่ต้องการ

- สินค้าที่ทราบว่ามีอยู่ใน GISP: แนบภาพพร้อมรหัสสินค้าหรือชื่อ ถ่ายได้ทั้งมุมปกติและอีกมุม
- สินค้าที่อยากได้รุ่นคล้าย: ระบุว่าความคล้ายที่ต้องการเน้นรูปทรง สี หรือวัสดุ
- รูปที่ไม่ควรพบสินค้าใกล้เคียง: ใช้ตรวจว่าระบบกล้าบอก “ไม่พบ” แทนการคืนสินค้าที่ไม่เกี่ยวข้อง

เริ่มส่ง 10–20 รูปก่อนได้ หากยังไม่ครบชุดรับรองจะรายงานจำนวนที่ขาด
เป้าหมายชุดใหม่อย่างน้อย 60 คำค้น แบ่งภาพสินค้าเดิม/คล้าย/ไม่พบประมาณกลุ่มละ 20
แบ่งคำตอบสำหรับปรับเกณฑ์และวัดผลแยกกันก่อนรัน โดยไม่ใช้ภาพเดียวกันทั้งสองชุด
เจ้าหน้าที่ต้องตรวจภาพกลุ่ม “ไม่พบ” กับ Catalog จริงก่อนถือเป็นคำตอบอ้างอิง
